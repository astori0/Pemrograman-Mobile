# Praktikum Pemrograman Mobile

Repository ini berisi hasil praktikum Android Studio
dengan pembagian modul menggunakan branch.

## Daftar Modul
1. Arsitektur Android
2. Layout Android
3. Gaya dan Tema Android
4. Activity Android
5. Intent Android
6. Fragment Android
7. Database Android (SQLite)
8. Web Service Android
9. Publikasi Android

Setiap modul berada pada branch masing-masing.
